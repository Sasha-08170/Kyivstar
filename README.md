# Чинити правильно прямо зараз — Раян Голідей

Интерактивная страница с обзором книги **«Чинити правильно прямо зараз»** (англ. *Right Thing, Right Now*) автора **Раяна Голідея**.
Проект создан с использованием **HTML**, **CSS (BEM, адаптив)** и **Vanilla JavaScript**.

---

## Функциональность

* 📚 **Информационный блок книги** — обложка, название, дата, категория, закладка.
* 🎧 **Кастомный аудиоплеер** — с кнопкой воспроизведения, таймлайном и отображением времени.
* 💬 **Секция комментариев** — интерактивная форма с валидацией и динамическим добавлением комментариев.
* ✅ **Валидация формы** — проверка заполненности и корректности email.
* 🕓 **Форматирование даты на украинском** при добавлении нового комментария.
* 📈 **SEO + Open Graph + JSON-LD** для поисковых систем и соцсетей.

---

## Используемые технологии

* **HTML5** — семантическая структура страницы
* **CSS3 (BEM + адаптив)** — современная типографика и стилизация под тёмную тему
* **Normalize.css** — сброс базовых стилей браузера
* **Vanilla JS (ES6)** — валидация формы и управление DOM
* **Schema.org / JSON-LD** — структурированные данные книги
